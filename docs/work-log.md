- 补齐 265 份真实 SWC 并核验官方校验和；复用 OpenEar ZETA 的 13 份 PLY，显示 TM、malleus、incus、stapes。
- 增加 tone、pulse、AM、chirp、noise、WAV，固定共享标定和独立感觉事件；参数修改后实际重算。
- 全部 265 个细胞记录膜电压；突触到达事件由监测的前突触发放和实际模型延迟导出。
- 增加选细胞/选边、0.1 ms/帧慢放、raster、放电率、latency、SWC 同步状态、条件比较和离线报告。
- 实机交互发现 Brian2 首次导入的主线程限制，已在服务启动主线程导入后再串行执行仿真任务。
- 35 项 Python 检查、9 项浏览器检查通过；验证 HDF5 导入往返结果一致、拓扑/增益对照感觉输入哈希一致。
- 八组参考结果见工作总结；另经界面实际运行 300 Hz、IPI 48 ms，产生 1,006 次模型放电。
