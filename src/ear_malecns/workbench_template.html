科研对照与术语解释

打开 65 次实际运行的科研报告：等 RMS、配对对照、消融、95% 区间

JON / AMMC / WED

JON 是触角内把振动转换成神经信号的感觉细胞；AMMC 是触角机械感觉与运动中心，WED 是楔区，它们是听觉信息处理脑区。

SNN / LIF / 突触延迟

SNN 是通过离散放电事件传递信息的神经网络；LIF 是电压随时间衰减、累积输入后跨阈值放电的简化模型。延迟是模型中发放到作用于目标之间的时间。

RMS / IPI / envelope

RMS 是声音有效幅度；IPI 是相邻脉冲起始间隔；envelope 是波形幅度随时间变化的外轮廓。相同幅度但不同 IPI 未必具有相同能量。

Connectome / hop / SWC

连接组是神经元与突触的结构地图；hop 是经过连接边的层数；SWC 保存分支形态。形态颜色仅映射模型状态。

配对 / 消融 / 置信区间

配对让条件共享相同随机输入；消融移除一类连接以检验作用；置信区间描述重采样估计的波动。随机种子不是生物个体。

FEM / TM / stapes / AdEx

FEM 是有限元机械求解；TM 是鼓膜；stapes 是镫骨；AdEx 是带适应机制的扩展发放模型，当前尚未实现。
